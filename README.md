Smart Study-Time Analyzer

INTRODUCTION

Smart Study-Time Analyzer is a C++ console-based project developed to analyze a student’s daily study habits and productivity.

The program takes inputs such as:
 > Study Hours
 > Mobile Usage Hours
 > Break Hours
 > Sleep Hours

Based on these inputs, the system calculates:
 > Focus Score
 > Productive Study Hours
 > Grade
 > Productivity Level

It also provides suggestions to help students improve their study routine and productivity.

FEATURES
 > Productivity Analysis
 > Focus Score Calculation
 > Grade Generation
 > Smart Suggestions System

Technologies Used
- C++
- Object-Oriented Programming (OOP)
- VS Code

Concepts Used
- Classes and Objects
- Functions
- Conditional Statements
- User Input and Output
